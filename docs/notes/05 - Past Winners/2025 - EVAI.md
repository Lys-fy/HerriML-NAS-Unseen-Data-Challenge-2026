## Per-dataset analysis

- **[[GameOfLife]]**: ceiling-saturated. All top-3 hit ~10/10. Not a discriminator.
- **[[Windspeed]]**: noise-floor. EVAI's 17.4% was the leaderboard top, but the absolute number is low — likely the dataset is genuinely hard or has label noise. Search budget on Windspeed had near-zero ROI.
- **[[Cryptic]]**: the deciding dataset. EVAI 76.1% vs Sichuan-2 73.2% vs Sichuan-3 72.3%. Cryptic rewarded EGNAS's macro-search over the Sichuan group's predictor-guided approach.

EVAI also avoided the −10 cliff on every dataset — a property [[Reliability vs Peak]] argues is a hard prerequisite, not a tiebreaker.

## Method (summary — see [[EGNAS]] for full detail)

Sequential global NAS over a macro-micro search space:

1. Depth grow loop: start min-depth + max-width, train short, add a layer until accuracy plateaus.
2. Width shrink loop: reduce channel count while accuracy stays within tolerance.
3. Per-layer hill-climb over `{Conv, SepConv} × {3, 5, 7}` kernel size.

Key design properties:
- **No weight-sharing supernet.** Each candidate is trained from scratch (briefly).
- **No predictor.** Pure architecture-aware training: short epochs early, longer as depth grows.
- **Architecture-aware schedule** ("variable training schemes") is the core efficiency trick — early hill-climbs are cheap because nets are shallow.

Public code: `siddikui/Efficient-Macro-Micro-NAS` (see [[Repositories]]).

## Why EGNAS won

- **Macro search reaches custom topologies.** Cryptic likely has structure that benefits from a non-standard depth/width point. Predictor-guided methods are biased toward whatever distribution the predictor was pretrained on; EGNAS rebuilds from scratch per dataset.
- **Architecture-aware schedule fits time-constrained eval.** The competition gives ~1 hour per dataset in Phase 2 — EGNAS can stop at any point in the depth-grow loop with a usable architecture. Predictor-guided methods need a warm-up corpus first.
- **No supernet brittleness.** Weight-sharing methods can collapse to skip-connections on unfamiliar data ([[DARTS Family]]); EGNAS sidesteps this.

## Implications for HerriML

- **EGNAS is the obvious baseline.** Public code, reproducible, won the competition.
- **The method is implementable inside one dataset's clock budget** because the depth/width loops are interruptible — important for [[Phase 2 Submission Strategy]].
- **Cryptic's gap to the predictor approaches says custom search beats priors when data is far from CIFAR.** Reinforces [[Search vs Train Split]] toward more search budget.
