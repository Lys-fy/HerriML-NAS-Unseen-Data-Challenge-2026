## How to read this folder

The records are split into four themes plus a research scan folder and the live notes at the root.

**Themes:**

- **pipeline/** - the single version line, v1 through v10. v1-v7 are the aug-probe era (the probe-driven self-configuration thesis being tested inside what was Tier 2a), v8 is the clean aggregate of everything validated, v9 is the searched dilated backbone, and **v10 is the measure-gate-train pipeline that is ACTIVE now**. The v10 design note and idea ledger lives here too.
  - [[Pipeline v1-v7 - Aug Probe]], [[Pipeline v10 - Design + Idea Ledger]]
- **baselines/** - the reference methods the pipeline is measured against: the fixed CNN, augmentation + op search, and the EGNAS macro and full reimplementations.
  - [[Fixed CNN]], [[Aug + Op Search]], [[EGNAS Macro Diagnostic]], [[EGNAS Full]]
- **architecture/** - backbone investigations: the TCN excursion and the Language deep dive.
  - [[TCN Backbone Excursion]], [[Language Deep Dive]]
- **reliability/** - variance and ensembling investigations: the multi-seed variance sweep and the E1 ensemble.
  - [[Multi-Seed Variance]], [[Ensemble E1]]

**research/** - literature and idea scans ([[SOTA Scan - Novel Directions]], [[Next-Run Ideas - lecture-informed]]).

**images/** - auto-generated by the `dev/plot_*.py` scripts. Never hand-edited.

**Root (live notes - these get updated in place):**

- **[[Key Learnings]]** - distilled findings from every experiment. First-read on a context reset.
- **[[Run State + Handoff]]** - operational resume point: Spark state, the next-action queue, how to pull/aggregate/plot results.
- **[[Implementation Results Overview]]** - the run index. Scoreboard plus a per-note pointer to every experiment record.

**Sibling folder:**

- **../plan/** - the original build plan (Tier 0-4 plus Branches B1-B4). See [[Implementation Plan Overview]]. This is a historical document and **keeps its Tier vocabulary**; it is not renamed.

## Naming history

The naming drifted across three eras as the project's unit of iteration changed. On **2026-06-12** the Tier-era names were retired everywhere in favour of the scheme below, and the implementation records were split into the four themes above.

1. **"Tier N"** - stages of the **original build plan** (see [[Implementation Plan Overview]]). Tier 0 = hardcoded baseline, Tier 1 = augmentation + op search, Tier 2a/2b = the search methods, and so on. The build plan still uses this vocabulary as a historical document.
2. **"P1 vN"** - iterations of **Probe 1** (the aug-safety probe), built **inside Tier 2a** and now logged in [[Pipeline v1-v7 - Aug Probe]]. Here the version counter referred to the *probe*, not the whole pipeline. This is why the early v-numbers grew up under a Tier note.
3. **"v8 onward = the WHOLE pipeline"** - from v8 the version counter refers to the **entire pipeline**: **v8** = clean aggregate of everything validated, **v9** = searched dilated backbone, **v10** = measure-gate-train.

**Everywhere-consistent naming.** As of the 2026-06-12 reorg the code directories, log directories and image names all follow the same map. Examples from the canonical map:

- code dir `baselines/tier2a_p1_augsafety_v8` -> `baselines/v8`
- log dir `dev/logs/tier2bfull` -> `dev/logs/egnas_full`
- image `tier2a_p1_v6_s42_curves.png` -> `pipeline/v6_s42_curves.png`

(The code, log and image renames are tracked in the same canonical map and applied across `dev/` and `images/`.)
