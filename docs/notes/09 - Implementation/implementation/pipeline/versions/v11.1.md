# v11.1 - Informed-defaults, squeezed (the budget floor) + the 3-tier ladder plan

> **Status:** PLAN (agreed 2026-06-22) | **Topic:** consolidate v10 into the robust low-budget *floor* of a budget-adaptive ladder, and define the ladder (v11.1 floor / v11.2 macro hill-climb / v11.3 evolutionary) that the cluster era makes possible. | **Related:** [[v11]], [[v11.2]], [[v11.3]], [[Pipeline v10 - Design + Idea Ledger]], [[Key Learnings]], [[Run State + Handoff]]

## The realisation that drives this

v10 is **informed defaults + light local tuning**, not search: fingerprint -> hand-picked family default (tcn2d/conv) -> tiny depth/width grid -> train-to-budget. On almost every known dataset the "search" keeps the incumbent default and changes nothing beyond noise. The wins that built +62 came from **good fixed defaults** (tcn2d, +11), a **cheap binary probe** (aug), and **training longer** (train-to-budget) - not from searching. The v11 extensions sweep confirmed it bluntly: **"v10 has almost no architectural headroom left"** - exactly one known dataset (Chesseract, and its blind twin Sedol) improves under any architectural change; width search is a no-op; extra depth helps in isolation but still loses to the default.

So "real NAS" here is not about squeezing the **known** 13 (they are at ceiling). Its value is a **bet on the unseen data**: Phase 2/3 are hidden, our hand-picked defaults may be wrong for them, and a verified search is the only mechanism that can correct a wrong default **at runtime** - scaled by whatever budget the grader gives.

## The budget-adaptive ladder (the shape)

One dispatcher, three tiers, gated by the wall-clock budget measured on the unknown GPU (calibrate one epoch -> estimate budget -> pick tier; v10's self-calibration generalised). Lower tiers are the safety floor; higher tiers only ever fire on genuine **surplus** budget.

| Tier | What it is | Budget gate | Honest expectation |
|---|---|---|---|
| **v11.1** | Informed defaults, **squeezed**. v10 + the untested cheap levers: train-to-LR=0 / full anneal, a **properly-gated cross-family ensemble** for surplus time, the gated verified per-stage macro-attention (v11's verdict, replaces the fragile random arm). **Self-scales from seconds -> ~2h.** | **< ~1-2 h** | The robust floor. Guaranteed shippable. Small but real gain over v10, mostly from anneal + ensemble, not architecture. |
| **v11.2** | Heterogeneous micro-macro **hill-climb**, verify-before-adopt (built; Chesseract validated **+4.84**). | **~2-4 h** | Finds the lever where one exists (board-like / Sedol-class). Null elsewhere by design. |
| **v11.3** | **Evolutionary** (regularised evolution) over the same space, population parallelised across A100s. | **> ~4 h** | Ceiling-chaser. Only beats .2 if the hill-climb is local-optimum-limited. Cluster-only. |

**The precondition for the whole ladder (the decisive experiment):** time-ordering alone (.1 < .2 < .3 in compute, confirmed: v11.2 CIFARTile search = 895 min on GB10) does NOT justify the tiers. Gating .2 in at 4 h only pays off if, **at the same 4 h, the search beats just giving .1 that time** (train to LR=0, or fill the budget with the gated ensemble). That **iso-budget comparison** is the gate: run `v11.1 (default + ensemble + anneal)` vs `v11.2 (search)` at matched budget (2 h, 4 h), full-validated, on the 13 known sets **+ the blind customs (Sedol/Sloan/Cauchy)**, 3 seeds. If search wins beyond noise -> wire .2/.3 in as tiers. If it ties -> ship **v11.1-adaptive alone** and .2/.3 become thesis material (an honest "search does not beat informed defaults + ensemble" finding is itself a result).

## Phased plan (to July 1 Phase 2, then beyond)

- **Phase 0 - prep (now).** Consolidate v11.1 (anneal-to-0, gated ensemble, formalise low-budget self-scaling). Fix the two v11.2 blockers: (a) the per-stage op vocabulary crashes on odd encoded shapes (SpatialSelfAttn2D silent 0.0) -> **shape pre-filter** drops ops that fail a dummy forward on the real H x W; (b) the in-search reference is wrong because the customs carry **no `fp_corr1`** -> compute the fingerprint **inline** so the family default (and thus the v10-route reference) is correct. Stand up the cluster env + launch method (**user owns the cluster**).
- **Phase 1 - the decision experiment (cluster, user).** The iso-budget fight above. A 1 h 3-seed v11.1 baseline runs alongside to lock the shippable floor regardless of outcome.
- **Decision gate.** Ladder real -> wire .2 in. Ties -> ship v11.1-adaptive.
- **Phase 2 - lock the submission.** Dispatcher (as complex as the gate justifies), 1 h crash-safety + 30-min collapse + hard-kill tests, 3-seed validate, package.
- **Phase 3 - post-July-1 (thesis).** v11.3 evolutionary, built only if Phase 1 shows the hill-climb leaves headroom.

## Spark results — v11.2 search on the blind hold-out (2026-06-24)

After fixing the two v11.2 bugs (inline fingerprint so the customs route correctly; op shape-prefilter so SpatialSelfAttn2D is dropped rather than silently 0.0), the hill-climb search ran on the blind customs + controls, every winner full-budget-validated vs v10's real numbers:

| Dataset | search winner | search test | v10 real | margin | beats v10? |
|---|---|---|---|---|---|
| Cauchy | tcn2d | 93.96 | 93.91 | +0.05 | tie |
| Sloan | tcn1d | 84.63 | 84.60 | +0.03 | tie |
| Gutenberg | searched | 47.02 | 47.28 | -0.26 | no |
| Sedol | tcn2d | 55.39 | 56.55 | -1.16 | no |
| Sudoku | tcn2d | 87.78 | 97.70 | -9.92 | no |

**Verdict: search beats real v10 on 0/5 hold-out datasets** — two noise-ties (the search rediscovering v10's own default) and three losses. Three diagnostics:
1. **Sudoku -9.92 (the headline):** the in-search bake-off ranked tcn2d best and ADOPTED it (`adopt=True`), but at full budget tcn2d gets 87.78 vs v10's conv route 97.70. The search's *own* adopt rule would have shipped a 10-point regression; **only the separate post-hoc validation caught it.** Lesson: verify-before-adopt must run on the *real* recipe (aug/EMA), not the search recipe, or it is unsafe to deploy standalone.
2. **Sedol -1.16:** the Chesseract twin did NOT reproduce the Chesseract attention win — the attention op is shape-filtered out on the 19x19 grid AND the bake-off picked tcn2d. The one genuine lever does not transfer without a shape-robust attention op.
3. **Cauchy/Sloan ties:** the search just rediscovered v10's default family. No new architecture, no gain.

This (single-seed, GB10) strongly predicts the cluster's iso-budget verdict: **the heterogeneous hill-climb does not beat informed defaults on unseen data.** Combined with the known-data picture (only Chesseract wins, itself a lever v10's random arm already found), the gate is leaning toward *ship v11.1-adaptive; v11.2/.3 are the thesis story.*

## Real-search tests queued (2026-06-24): faithful EGNAS + evolution

Two "is it really the search or our port?" tests are running on Spark (`dev/queue_search_tests.sh`), each discovered arch full-budget-validated:
- **`dev/egnas_faithful.py`** — the REAL 2025-winning EGNAS, verified line-by-line against upstream (siddikui/Efficient-Macro-Micro-NAS `search.py` + arXiv:2502.03553 Algorithm 1), not our v6/v7 port. Exact spec: init SepConv3 x10 @ W_max; macro grow (+1 layer, +1 epoch, commit on +0.10pp, 2-strike break, never revert); macro width-prune (-2 ch, +2 epoch, accept any non-degradation, 2-strike); micro per-layer Sep->Conv then K3->K5, param-equalised (shrink global channels to hold params within +0.01M), **E_min=2, NO verification of accepts**. Tests the open question (our EGNAS reimpl is suspected wrong; real EGNAS beats v10 on Cryptic). Documented budget-clamps: W_max=64 (paper "Tiny"), per-cand epoch cap, val-acc ranking (legal), final train delegated to validate_winner. Added `SepConv5` to OP_VOCAB for the 4-op `{Conv,Sep}x{3,5}` vocabulary.
- **`dev/evo_search.py`** — the [[v11.3]] regularised (aging) evolution over the heterogeneous space: population seeded from v10-route + random, tournament selection by cheap-screen, mutate (op-swap / add-layer / remove-layer / width), remove-oldest; commit = verify top-K, validate the best at full budget. The non-greedy alternative to v11.2's hill-climb.

Both run all 16 datasets (decision-relevant first); results to `~/local/{egnas_faithful,evo}{,_validated}`.

## Faithful-EGNAS + evolution verdict (seed 42, full-budget, all 16) — 2026-06-29

The faithful EGNAS (verified vs upstream `search.py` + Algorithm 1) and the v11.3 evolution were searched and full-budget-validated on all 16 datasets. **The open question — "is our EGNAS port wrong; would real EGNAS beat v10?" — is decisively answered: NO.**

- **Faithful EGNAS: net −69.9 pp vs v10** (mean −4.4/ds, wins 2/16 trivially). It converges to **deep uniform SepConv3 on every dataset** (its conv-only vocab + strict micro-acceptance cannot produce heterogeneity), and **craters on Cryptic (−21.8) and CIFARTile (−26.1)** — Cryptic being *the* dataset it supposedly dominated in 2025. Real-EGNAS is a deep-conv *image* method, not a general one.
- **Evolution: net −25.9 pp** (mean −1.6, wins 5/16). Heterogeneous, **rediscovers attention exactly where it is the lever** (Chesseract +4.3, also appears on CIFARTile/Sloan/Language), but its wins do not cover its losses on CIFARTile (−13) and Language (−11), where v10's informed routing nails a structural lever the search vocab/proxy cannot.
- **Both are net-negative vs v10.** Confirms the project thesis hard: informed defaults + a couple of known levers beat general architecture search on this benchmark at this budget.

## v11.1 verdict + the 3-way bake-off (seed 42) — 2026-06-29

v11.1 was run end-to-end (search → train-to-budget → predict) on all 16, head-to-head with EGNAS and evolution against v10's s42 numbers.

![[bakeoff_s42.png]]
> *Margin vs v10 per dataset (top) + mean-margin summary (bottom). v11.1 green, EGNAS red, evolution blue. Regenerate: `python3 dev/plot_bakeoff.py`.*

| method | mean margin vs v10 | total | W/T/L |
|---|---|---|---|
| **v11.1 (floor)** | **−0.63 pp** | −10.0 | 2/5/9 |
| evolution | −1.62 pp | −25.9 | 5/3/8 |
| EGNAS-faithful | −4.37 pp | −69.9 | 2/4/10 |

**Key findings:**
1. **The attention probe works.** v11.1 fires and adopts early attention on **Chesseract → 62.48, +4.82** (arch `attn[2×Attn+Conv3]`), matching the evolution's +4.31 and the v11.2 hill-climb's +4.84 — a FOURTH independent confirmation of the one real lever. **Zero false adoptions** elsewhere (every other encoded dataset kept its family default), so the probe is well-behaved.
2. **v11.1 is clearly the best of the three** (mean −0.63 vs evolution −1.62 vs EGNAS −4.37) and dominates both searches on the hard datasets (CIFARTile 70.8 vs evo 60.4 / EGNAS 47.6; Language 88.7 vs ~79 for both). It IS v10 + the lever, so it inherits v10's strength and adds the Chesseract win.
3. **The −0.63 net-negative is concentrated in a few high-variance encoded datasets** (Cryptic −4.9, Sudoku −3.3, CIFARTile −2.8) on this **single seed**, vs the *older* v10 run — most consistent with run-to-run variance (cudnn nondeterminism + fresh search picks; Sudoku picked conv D=8 vs v10's D=6) rather than a real regression. **The 3-seed sweep (running) resolves this** — and is the reason it was launched.
