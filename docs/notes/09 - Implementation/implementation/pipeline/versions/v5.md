## What was done

Three bundled changes: (1) swap the probe driver A -> **C (multi-trial K=8)** per the v4 shadow finding; (2) **Mixup alpha=0.2** auto-applied whenever the probe decides OFF; (3) extend OP_VOCAB with **GroupConv3 + ResNeXt** (the grouped-conv lever flagged by [[Language Deep Dive]]).

## Why (motivation; what changed from v4)

v4's shadow data said K=8 fixes the borderline misses, so the driver swap was a one-line, data-backed change. The new ops and Mixup were the architectural and regularisation levers the Language deep dive proposed.

## Verdict / carried forward

Adding ops to a noisy short-train ranker manufactures false positives; the per-op signal is unreliable. Also surfaced a methodology mismatch with upstream EGNAS (their 4-op binary vocab, 600-epoch final train). Carried forward to v6: EGNAS-faithful methodology + verification-of-accepts.
