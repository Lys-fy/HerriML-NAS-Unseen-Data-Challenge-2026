# v1 - aug-probe, raw-val rule (failed smoke)

> **Status:** failed smoke, never swept | **Dates:** 2026-05 | **Code dir:** (no preserved baseline) | **Total adj:** n/a | **Deep-dive:** [[Pipeline v1-v7 - Aug Probe]]

## What was done

The first actual probe of the [[Probe-Driven Self-Configuration]] thesis. At `NAS.search()` start, train two tiny models (aug-on vs aug-off) at K=4 short epochs and pick the augmentation policy by raw validation accuracy. Rule: turn aug **OFF iff `val_off - val_on > 0.5 pp`**.

## Why (motivation; what changed from baseline)

[[Aug + Op Search]] proved augmentation is double-edged: +11.86 on AddNIST but -5.65 on Language, and metadata alone cannot tell which case a dataset is. A runtime aug-safety probe was the data-backed #1 priority to recover the Language-class regression without losing the AddNIST-class gains.

## Tested

Smoke test on AddNIST only.

## Results

Smoke **FAILED**. At K=4, aug-off val (0.208) read higher than aug-on (0.162), so the rule picked OFF on AddNIST, which the multi-seed sweep shows craters to the -10 floor.

## Verdict / carried forward

The raw-val rule is fooled because **aug-off over-fits faster at short horizons**, making its raw val misleadingly high. Carried forward: penalise the over-fit signature (the train-val gap), which became the v2 rule.
