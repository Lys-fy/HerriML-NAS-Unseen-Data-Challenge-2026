# v10 - measure-gate-train (all-time best)

> **Status:** BUILT + 3-seed sweep scored; the all-time best | **Dates:** built 2026-06-11, sweep scored 2026-06-14 | **Code dir:** `baselines/v10` | **Total adj:** **+62.49** (s42), **+62.23 +/- 0.19** (3-seed) | **Deep-dive:** [[Pipeline v10 - Design + Idea Ledger]]

## What was done

The consolidated **measure-gate-train** pipeline: per dataset, measure first, decide only when the evidence beats the noise, otherwise keep the strong default, and spend every saved minute training. Stages: a corr1 **fingerprint** (CPU, seconds) routes encoded data to a 3-arm backbone gate (conv/tcn1d/tcn2d, abstain-to-conv) and image-like data straight to TCN-2d; a **family-matched aug probe** runs AFTER the backbone choice; **default-incumbent depth** (D=6 vs {4,8}, verified wins only); NO width search; a budget-gated **random arm** on encoded data; then **train-to-budget**. Every stage appends to a per-dataset decision record, with low-budget collapse below 35/15 min. Budgets are fractions of the clock, never fixed minutes.

## Why (motivation; what changed from v9)

Phase A (A1-A6, Blocks A/B) settled the design. Key corrections over v9: v9's searched depth net-hurts -> default-incumbent rule + drop width search; A5b found **aug decisions do not transfer across backbone families** -> relocate the aug probe after the backbone choice; the fingerprint SKIP is load-bearing (gating every dataset scores +58.5, below the +59.2 fixed default; fingerprint-routed gating +61.2).

## Tested

Phase A bake-off (39 live curves), then the standard **v10 x 3 seeds x 13 datasets x 2h** sweep. Smoke passed on all four paths (collapse, image-skip, full encoded).
