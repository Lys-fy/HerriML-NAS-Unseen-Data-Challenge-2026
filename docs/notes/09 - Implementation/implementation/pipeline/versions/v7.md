# v7 - SIMPLIFY (EGNAS-full + aug-probe + macro-prune-verify)

> **Status:** swept, BEATS EGNAS-full (first time) | **Dates:** 2026-06-03 | **Code dir:** `baselines/v7` | **Total adj:** **+41.94 +/- 3.45** internal, Δmean **+6.43** vs EGNAS-full, sigma x1.12 | **Deep-dive:** [[Pipeline v1-v7 - Aug Probe]]

## What was done

The pivot from v6: a clean EGNAS-full search with **only 4 conv ops** (Conv3/Conv5/Conv7/SepConv3), plus **macro-prune-verify** (depth verify-of-rejects + width verify-of-accepts) and the **C-only aug-probe**. Exotic and recurrent ops are tested out-of-band, not in the live search.

## Why (motivation; what changed from v6)

v6 proved the rich vocab is a liability and the macro search mis-prunes at both boundaries. v7 strips the vocab back, adds the symmetric verification that cures depth false-strikes (GameOfLife) and width false-accepts (Sudoku), and keeps the one component that ever helped: the Language aug-probe.

## Tested

Full sweep, 13 datasets x 3 seeds. Plus the out-of-band **LSTM Language probe** (fixed-arch full-budget A/B): row-BiLSTM reached **85.76% on all 3 seeds**, the first arch in the project reliably above the Language benchmark; attention did not cross (84.8%); cross-axis BiLSTM was unstable.

**+41.94 vs EGNAS-full +35.51 (Δ+6.43)** with sigma essentially flat. The win is dominated by **Language Δ+7.34** (aug-probe OFF all 3 seeds); the macro-verify's real job was stabilising archs so the aug-off gain is not eaten by variance. One regression: **MultNIST -1.15**.

## Verdict / carried forward

First version to beat the proven EGNAS-full baseline. **The aug-probe is the engine, not the search.** Recurrence is real but cannot live in the search (its SGD proxy cannot train an LSTM) -> deploy via a fail-safe convergence A/B. Carried forward: train-to-budget and the data-preprocessing lever (v8), and the MultNIST recovery.
