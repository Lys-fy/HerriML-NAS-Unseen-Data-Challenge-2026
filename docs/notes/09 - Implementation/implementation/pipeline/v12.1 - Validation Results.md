## 4. What did we learn (v12.1 adoption case)

1. **Adopt v12.1(b)**: >= v12 at 2h, sweeps all records at 8h, every mechanism observed
   working in production (hardened probes incl. honest sub-noise rejects, alt-family seed
   [ensemble with a WEAKER alt beat same-family top2 by +1.3], top-ups to the 8-seed cap,
   top-m, band, capacity arm) with zero crashes across ~40 dataset-runs.
2. Residual gate variance at 2h (Chesseract -2.8 roll) is the one soft spot -> candidate
   one-constant fix: extend probe floors below the 4h threshold.
3. Diversity hierarchy settled: trajectory noise + TA (free) > alt-family (cheap, hedges
   gates) > capacity twin (scalers only) > indep init (negative) > wider W128 (negative).
4. Compute converts to accuracy ONLY on scaler datasets (CIFARTile +6.4 for 4x budget;
   Language +2.4; Sudoku +1.7 via seeds) -- ceiling/noise/plateau sets are flat, which is
   exactly what the val-gated ladder prices in automatically.
