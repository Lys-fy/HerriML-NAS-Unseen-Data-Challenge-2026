## 4. What did we learn (v12.1 adoption case)

1. **Adopt v12.1(b)**: >= v12 at 2h, sweeps all records at 8h, every mechanism observed
   working in production (hardened probes incl. honest sub-noise rejects, alt-family seed
   [ensemble with a WEAKER alt beat same-family top2 by +1.3], top-ups to the 8-seed cap,
   top-m, band, capacity arm) with zero crashes across ~40 dataset-runs.
2. Residual gate variance at 2h (Chesseract -2.8 roll) is the one soft spot -> candidate
   one-constant fix: extend probe floors below the 4h threshold.
3. Diversity hierarchy settled: trajectory noise + TA (free) > alt-family (cheap, hedges
   gates) > capacity twin (scalers only) > indep init (negative) > wider W128 (negative).
4. Compute converts to accuracy ONLY on scaler datasets (CIFARTile +6.4 for 4x budget;
   Language +2.4; Sudoku +1.7 via seeds) -- ceiling/noise/plateau sets are flat, which is
   exactly what the val-gated ladder prices in automatically.

# v13 -- FINAL (adopted, validated, shipped 2026-07-16)

> Full pipeline spec: [[Pipeline v13 - Final Spec]]. **v13 = v12.1 + exactly two
> dataset-agnostic changes**, both validated below: (1) gate tie-break default OFF,
> (2) saturation early-stop. Shipped as `submissions/v2` (cleaned); `submissions/v1`
> = v12.1 fallback. Phase-2 email (v13) sent 2026-07-16.

## v13.1 The two changes
1. **Tie-break OFF** (was v12.4 verdict): the sub-noise family race re-measure is a
   val->test MISMATCH -- more probe resolution buys a more confident WRONG family
   (pooled Chesseract @2h: OFF 65.42 vs ON 63.35, n=6 vs 4). The abstain-to-incumbent
   + alt-family hedge already cover the race far more cheaply.
2. **Saturation early-stop** (dataset-agnostic): the patience anchor advances only on a
   val gain that clears the run's OWN measured noise (std of a recent window); once val
   plateaus the anchor freezes and the seed stops after a schedule-relative window (25%),
   releasing its slice to more seeds. Nothing keyed to board size or the known 16. Fixes
   the v12.4 T3 inversion (a fast GPU ran the full CAP_EPOCHS schedule on a small board
   and overfit -- Chesseract @8h GB10 landed 63.2, worse than @2h).

## v13.2 Validation (8h, GB10) -- the saturation thesis holds
| test | SATURATE | result | verdict |
|---|---|---|---|
| Chesseract | **ON** | **67.41** | the inversion, recovered |
| Chesseract | OFF | 64.59 | attribution: off drops it ~2.8pp |
| CIFARTile | ON | 87.08 | scaler NOT over-stopped |
| Sudoku | ON | 96.72 | small board NOT over-stopped; seeds 5-7 saturated -> released slices -> 8-seed roster |
| **Cryptic** | ON | **78.60** | new all-time best, token family + 8-seed ensemble, **+2.4 over the 2025 winner (76.15)** |

So the saturation stop recovers the one dataset it was built for and does not hurt the
long-training beneficiaries -- exactly the intended dataset-agnostic behavior.

## v13.4 Equivalence proof (cleaned submission == validated baseline)
The shipped code is `baselines/v13` cleaned (comments stripped, dead code removed,
env-defaults hardcoded, off-by-default features deleted). Proven equivalent two ways:
- **Static**: every kept constant has the IDENTICAL value to the baseline env-default
  (nas 21/21, trainer 20/20); every removed feature's master gate was `False`.
- **Runtime** (paired GPU runs, `dev/verify_submissions.sh`): clean-vs-baseline
  prediction agreement sits INSIDE the baseline-vs-baseline run-noise floor
  (Chesseract clean 80.3% vs its own noise floor 81.5%; Cryptic 83.6%, both -> token;
  Sudoku 96.3%, both -> conv; **CIFARTile identical 80.030 = 80.030**, same arch/plan/
  selection). The pipeline is inherently nondeterministic on the coin-flip gate; the
  cleanup adds no deviation beyond that.
